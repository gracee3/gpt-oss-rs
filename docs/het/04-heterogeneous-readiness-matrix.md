# Heterogeneous readiness matrix

Statuses describe the capability named in the first column, not a nearby
component. `implemented-and-validated` requires retained evidence at the stated
scope; `implemented-not-validated-here` means a real source path exists but
this host/phase supplies no qualifying run; `partial/scaffold` means only part
of the required mechanism exists.

## Readiness conclusion

The repository is not one abstraction away from the provisional proof. Its
best reusable evidence is the exact CPU route/expert/reduction trace and
transactional state boundary. CUDA supplies useful kernels, a real single-GPU
decode path and partial NCCL infrastructure, but current prefill, weight
ownership, TP dimensions, scratch accounting, transfers and rollback do not
yet establish a heterogeneous execution mechanism. Research must resolve those
facts before planning.
